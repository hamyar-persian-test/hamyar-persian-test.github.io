Security Policy
This policy applies to the Hamyar Persian IT-Service static website hosted on GitHub Pages. 
The site presents computer and IT services in Persian and German. It has no website accounts, contact form, payment processing, or database. 
Its contact buttons link to Instagram and to the visitor’s email application.

Supported Versions
Version	Security support
Current static site published from this repository	Supported
Older ZIP packages, archived versions, and third-party forks	Not maintained
Scope
Please report security issues in this repository’s HTML, CSS, JavaScript, published assets, or Pages configuration that affect the static website. 
Examples include unintended publication of non-public data, unexpected script execution, and an unsafe redirect caused by the site’s own code or links.

The separate WordPress site, the GitHub platform, Instagram, and email providers are outside this policy’s scope.
Report problems in those services to their respective operators. Ordinary display issues or broken links without a security impact can be reported as regular issues.

Reporting a Vulnerability
Please report security issues privately:

If Report a vulnerability is available in this repository’s security tab, use that form.
Otherwise, email hamyar.persian_computer@hotmail.com with the subject [Security] Hamyar Persian IT-Service.
Include the affected URL or file, what you observed, and the potential impact. 
Browser details or a screenshot with sensitive information removed can help. 
Do not send passwords, tokens, or personal data. Please do not post vulnerability details in public issues or pull requests, and do not access anyone else’s data or disrupt the site while investigating.

What to Expect
Reports are reviewed on a best-effort basis. We may ask for clarification and aim to send private updates when there is meaningful progress. 
Confirmed issues are prioritized by impact; if an issue is out of scope or cannot be verified, we aim to explain why. 
There is no guaranteed response or fix deadline. Please give us a reasonable chance to investigate before publicly disclosing the issue.
